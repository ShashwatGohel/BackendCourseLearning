# Backend Engineering Learning (Day-wise)

This repository is my **daily backend engineering practice log** (from scratch).  
Each `Day-*` folder contains:
- runnable practice code (mostly Node.js/Express)
- a `README.md` that teaches what I learned that day (medium depth)
- a short list of **interview-style questions/tasks** I practiced

If you’re a beginner, the best way to use this repo is:
1. Pick a day/topic from the table below
2. Open that `Day-*` folder
3. Read the day’s `README.md` first, then explore the code files

---

## Prerequisites
- Node.js installed (LTS recommended)
- Basic JavaScript fundamentals
- For MongoDB days: MongoDB running locally (or a cloud URI)

Install dependencies once at repo root:
```bash
npm install
```

Run a specific file (example):
```bash
node Day-1/app.js
```
